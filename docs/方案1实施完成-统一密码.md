### 二、后端服务层改进

**文件**：`backend/services/application_permission_service.go`

#### 1. 创建用户时生成密码

```go
// CreateAuthUser 创建授权中心用户，返回生成的密码
func (s *ApplicationPermissionService) CreateAuthUser(user *models.AuthUser) (string, error) {
    // 生成随机密码
    password, err := GenerateRandomPassword(DefaultPasswordConfig)
    if err != nil {
        return "", fmt.Errorf("生成密码失败: %w", err)
    }

    // 存储密码
    user.Password = password

    if err := db.Create(user).Error; err != nil {
        return "", err
    }

    // 返回明文密码，用于显示给管理员
    return password, nil
}
```

#### 2. 授权时使用用户密码

```go
// AssignRoleToUser 为用户分配本地角色
func (s *ApplicationPermissionService) AssignRoleToUser(userID, roleID uint, operator string) ([]ExternalUserResult, error) {
    // 获取用户信息
    var user models.AuthUser
    if err := db.First(&user, userID).Error; err != nil {
        return nil, fmt.Errorf("获取用户信息失败: %w", err)
    }

    // 检查用户是否有密码
    if user.Password == "" {
        return nil, fmt.Errorf("用户未设置初始密码，请先重置用户密码")
    }

    // 使用用户的统一密码创建外部用户
    s.CreateExternalUser(binding.AppID, user.Username, user.Password, user.Email, user.Nickname, operator)
}
```

### 三、后端控制器改进

**文件**：`backend/controllers/application_permission.go`

```go
// CreateAuthUser 创建授权中心用户
func (ctrl *ApplicationPermissionController) CreateAuthUser(c *gin.Context) {
    var req models.AuthUser
    if err := c.ShouldBindJSON(&req); err != nil {
        c.JSON(http.StatusOK, utils.ErrorInternal("参数错误"))
        return
    }

    password, err := ctrl.service.CreateAuthUser(&req)
    if err != nil {
        c.JSON(http.StatusOK, utils.ErrorInternal("创建用户失败"))
        return
    }

    // 返回用户信息和初始密码
    c.JSON(http.StatusOK, utils.SuccessWithData(gin.H{
        "id":          req.ID,
        "username":    req.Username,
        "nickname":    req.Nickname,
        "email":       req.Email,
        "phone":       req.Phone,
        "description": req.Description,
        "status":      req.Status,
        "password":    password, // 返回明文密码，仅在创建时显示一次
        "message":     "用户创建成功，请妥善保管初始密码",
    }))
}
```

**改进点**：

        passwordDialogVisible.value = true;
      }
    }
  }
}

## 技术细节说明

### 密码生成算法

**文件**：`backend/services/password_generator.go`

```go
type PasswordConfig struct {
    Length      int
    UpperCount  int    // 大写字母数量
    LowerCount  int    // 小写字母数量
    DigitCount  int    // 数字数量
    SpecialChar string // 特殊字符
}

var DefaultPasswordConfig = PasswordConfig{
    Length:      12,
    UpperCount:  2,
    LowerCount:  4,
    DigitCount:  4,
    SpecialChar: "@#$%",
}

func GenerateRandomPassword(config PasswordConfig) (string, error)
```

**特点**：
- 使用加密安全的随机数生成器 `crypto/rand`
- 保证密码复杂度（大小写、数字、特殊字符）
- 可配置密码策略
- 随机打乱字符顺序

### 密码存储

**当前实现**：
- 密码以明文存储在 `auth_users.password` 字段
- 使用 `json:"-"` 标签，不会在API响应中返回

**安全建议**（后续改进）：
