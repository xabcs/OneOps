# 查看同步的角色和用户 - 使用指南

## 问题

用户反馈：同步角色成功后，不知道在哪里查看同步的角色。

## 解决方案

在**应用管理**页面添加了两个新功能：
- ✅ **查看角色**：查看应用同步的角色列表
- ✅ **查看用户**：查看应用同步的用户列表

## 功能说明

### 1. 查看角色

**入口：** 应用管理 > 某应用的"查看角色"按钮

**功能：**
- 显示该应用同步的所有角色
- 包含：角色代码、角色名称、角色类型、描述、同步时间
- 如果没有角色，提示"请先同步角色"

**使用场景：**
- 确认角色是否同步成功
- 查看可用的外部角色
- 了解角色的详细信息

### 2. 查看用户

**入口：** 应用管理 > 某应用的"查看用户"按钮

**功能：**
- 显示该应用同步的所有用户
- 包含：用户名、显示名称、邮箱、状态、同步时间
- 如果没有用户，提示"请先同步用户"

**使用场景：**
- 确认用户是否同步成功
- 查看外部系统的用户列表
- 了解用户的详细信息

### 3. 同步后自动显示

**改进：** 同步角色/用户成功后，**自动弹出列表对话框**显示结果

**好处：**
- 立即看到同步结果
- 确认同步是否成功
- 无需额外点击

## 操作流程

### 方式一：先同步，再查看

```
1. 进入"授权中心 > 应用管理"
2. 找到目标应用（如 Jenkins）
3. 点击"同步角色"按钮
   ↓
   显示成功消息
4. 点击"查看角色"按钮
   ↓
   弹出对话框显示角色列表
```

### 方式二：同步后自动显示（推荐）

```
1. 进入"授权中心 > 应用管理"
2. 找到目标应用（如 Jenkins）
3. 点击"同步角色"按钮
   ↓
   同步成功后自动弹出角色列表对话框
   ↓
   查看同步的角色
```

## 后续使用

同步的角色可以在以下地方使用：

### 1. 角色绑定

**位置：** 授权中心 > 角色绑定

**作用：** 将授权中心角色映射到外部应用角色

**操作：**
```
1. 选择授权中心角色（如"开发人员"）
2. 点击"添加绑定"
3. 选择应用（如 Jenkins）
4. 选择外部角色（从同步的角色列表中选择）
5. 保存
```

### 2. 用户授权

**位置：** 授权中心 > 用户授权

**作用：** 为用户分配角色，自动在外部系统创建用户并授权

**操作：**
```
1. 选择用户
2. 点击"分配角色"
3. 选择角色（包含绑定的外部角色）
4. 系统自动：
   - 在外部系统创建用户（如果不存在）
   - 分配对应的外部角色
```

## 代码变更

**修改文件：** `frontend/src/views/auth/applications/index.vue`

**新增功能：**

1. **导入 API：**
   - `fetchApplicationRoles` - 获取应用角色列表
   - `fetchApplicationUsers` - 获取应用用户列表

2. **新增状态：**
   - `rolesDialogVisible` - 角色对话框显示状态
   - `usersDialogVisible` - 用户对话框显示状态
   - `applicationRoles` - 应用角色列表
   - `applicationUsers` - 应用用户列表
   - `currentAppName` - 当前应用名称

3. **新增函数：**
   - `handleViewRoles()` - 查看角色列表
   - `handleViewUsers()` - 查看用户列表
   - 同步成功后自动调用查看函数

4. **UI 改进：**
   - 操作列增加"查看角色"和"查看用户"按钮
   - 添加角色列表对话框
   - 添加用户列表对话框

## 数据流程

```
用户点击"同步角色"
     ↓
调用后端 API：POST /system/applications/{id}/sync-roles
     ↓
后端通过 Script Console 获取 Jenkins 角色
     ↓
保存到数据库：application_roles 表
     ↓
返回成功
     ↓
自动调用：fetchApplicationRoles(id)
     ↓
显示角色列表对话框
```

## 数据库表

### application_roles 表结构

```sql
CREATE TABLE application_roles (
  id INT PRIMARY KEY AUTO_INCREMENT,
  app_id INT NOT NULL,              -- 应用 ID
  role_code VARCHAR(100) NOT NULL,   -- 角色代码
  role_name VARCHAR(100) NOT NULL,   -- 角色名称
  role_type VARCHAR(50),             -- 角色类型（global/item）
  description VARCHAR(200),          -- 描述
  sync_time DATETIME,                -- 同步时间
  created_at DATETIME,
  updated_at DATETIME
);
```

### application_users 表结构

```sql
CREATE TABLE application_users (
  id INT PRIMARY KEY AUTO_INCREMENT,
  app_id INT NOT NULL,              -- 应用 ID
  username VARCHAR(100) NOT NULL,    -- 用户名
  display_name VARCHAR(100),         -- 显示名称
  email VARCHAR(100),                -- 邮箱
  status VARCHAR(20),                -- 状态
  sync_time DATETIME,                -- 同步时间
  created_at DATETIME,
  updated_at DATETIME
);
```

## 常见问题

### Q: 为什么看不到角色？

**可能原因：**
1. 还没有同步角色
2. 同步失败
3. 外部系统没有角色

**解决方法：**
1. 点击"同步角色"按钮
2. 检查同步是否成功
3. 查看操作日志了解失败原因

### Q: 同步的角色在哪里使用？

**回答：** 在"角色绑定"页面，选择应用时会自动加载该应用同步的角色列表。

### Q: 为什么同步后角色列表为空？

**可能原因：**
1. Jenkins 未安装 Role Strategy 插件
2. 未配置 Role-Based Strategy
3. Jenkins 中没有创建角色

**解决方法：**
1. 安装 "Role-based Authorization Strategy" 插件
2. 在全局安全配置中启用 "Role-Based Strategy"
3. 在 "Manage Roles" 中创建角色
