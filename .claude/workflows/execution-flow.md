## 与传统 Agent 调用的对比

### 传统方式（顺序执行）

```
会话 Context：
┌────────────────────────────────────┐
│ 用户请求                            │
├────────────────────────────────────┤
│ Agent 1 扫描路由                    │ → 占用 Context
│   结果: [87个路由]                  │
├────────────────────────────────────┤
│ Agent 2 分析安全                    │ → 占用 Context
│   输入: [87个路由]                  │
│   结果: {3个问题}                   │
├────────────────────────────────────┤
│ Agent 3 验证问题                    │ → 占用 Context
│   输入: {3个问题}                   │
│   结果: {确认2个}                   │
├────────────────────────────────────┤
│ Agent 4 生成报告                    │ → 占用 Context
│   输入: {确认2个}                   │
│   结果: [Markdown报告]             │
├────────────────────────────────────┤
│ 返回给用户                          │
└────────────────────────────────────┘
```

**问题**：
- 每个 Agent 的结果都占用主会话 Context
- 无法并行执行
- 中间过程无法暂停/恢复

### Workflow 方式（后台执行）

```
会话 Context：
┌────────────────────────────────────┐
│ 用户请求                            │
├────────────────────────────────────┤
│ ┌──────────────────────────────┐   │
│ │  Workflow 运行时（隔离）      │   │
│ │  ┌────────────────────────┐  │   │
│ │  │ Agent 1 → Agent 2      │  │   │
│ │  │   ↓         ↓          │  │   │
│ │  │ Agent 3 → Agent 4      │  │   │
│ │  └────────────────────────┘  │   │
│ │         所有中间结果在         │   │
│ │       脚本变量中              │   │
│ └──────────────────────────────┘   │
├────────────────────────────────────┤
│ 仅返回最终结果                      │
│ [Markdown报告]                     │
└────────────────────────────────────┘
```

**优势**：
- ✅ 中间结果不占用 Context
- ✅ 可以并行执行多个 Agent
- ✅ 可以暂停/恢复
- ✅ 可以保存为可重用脚本

## 实际使用体验

### 触发 Workflow

```bash
# 方式 1: 使用 ultracode 关键词
ultracode: 审计所有 API 路由的安全配置

# 方式 2: 使用已保存的命令
/security-audit

# 方式 3: 设置 Ultracode 模式
/effort ultracode
审计所有 API 路由
```

### 监控执行

```bash
# 查看运行中的 Workflow
/workflows

# 输出示例:
┌─ Running Workflows ────────────────────────┐
│ ✅ security-audit                          │
│    Phase 2/4: 安全分析                      │
│    Agents: 2 并发运行中                    │
│    Tokens: 12,450 / ~50,000                │
│    Elapsed: 1m 23s                         │
└────────────────────────────────────────────┘

# 键盘快捷键
# ↑/↓ 选择阶段或 Agent
# Enter 查看详情
# p 暂停/恢复
# x 停止
# s 保存为命令
```

## 关键要点

1. **脚本化编排**：计划写入代码，可重复执行
2. **上下文隔离**：中间结果不占用主会话
3. **并行能力**：最多 16 个 Agent 并发
4. **可恢复性**：同一会话内可暂停/恢复
5. **可保存性**：保存为命令重复使用

这就是 Workflow 的核心价值：**将复杂任务自动化、规模化、脚本化**。
