# 终端工作台产品需求文档 (PRD)

## 一、产品概述

### 1.1 产品定位
终端工作台（Terminal Workbench）是 OneOps 运维管理平台的核心功能模块，为运维人员提供统一的 Web 终端访问入口，支持多会话管理、SSH/SFTP 连接、实时监控等功能，提升运维效率。

### 1.2 目标用户
- **主要用户**：系统管理员、运维工程师、DBA
- **次要用户**：开发人员、测试人员

### 1.3 核心价值
- **统一入口**：无需本地安装 SSH 客户端，浏览器即可访问所有服务器
- **安全管理**：集中管控访问权限，完整审计操作记录
- **高效协作**：多会话并行操作，快速切换服务器

## 二、功能需求

### 2.1 核心功能

#### 2.1.1 多会话管理
**需求描述**：用户可以同时创建多个终端会话，并在不同会话之间快速切换。

**功能规格**：
- 支持同时创建**无限制**数量的 SSH 终端会话
- 会话以标签页形式展示，显示服务器名称、IP、连接状态
- 支持会话的创建、切换、关闭
- 支持会话固定和自动关闭策略
- 每个会话完全独立，互不干扰

**交互设计**：
- 点击会话标签切换到对应会话
- 标签页显示连接状态指示器（绿色=已连接，黄色=连接中，灰色=已断开）
- 鼠标悬停显示会话详细信息（服务器IP、登录账号、连接时长）
- 支持快捷键切换会话（Cmd/Ctrl + 数字键）

#### 2.1.2 主机资产树
**需求描述**：左侧提供分组的主机资产列表，支持快速选择和连接主机。

**功能规格**：
- 按业务系统/机房机柜分层级展示服务器
- 支持搜索/过滤主机（按主机名、IP）
- 显示主机在线状态（通过 Agent 心跳）
- 双击主机快速创建连接
- 右键菜单提供更多操作（连接、新窗口打开、收藏）

**交互设计**：
- 树形结构展示，可折叠/展开
- 在线主机显示绿色指示点
- 已连接主机显示"已连接"标签
- 搜索框支持实时过滤

#### 2.1.3 SSH 终端连接
**需求描述**：提供完整的 SSH 终端模拟体验，支持全功能终端操作。

**功能规格**：
- 基于 xterm.js 的终端模拟
- 支持 256 色显示
- 支持终端大小自适应
- 支持中文显示和输入
- 支持复制粘贴操作
- 支持 scrollback 缓冲（建议保留 1000 行）

**交互设计**：
- 终端界面使用 VSCode 风格的暗色主题
- 支持全屏模式
- 支持字体大小调整（放大/缩小）
- 双击选中单词，三击选中整行

#### 2.1.4 连接管理
**需求描述**：提供服务器连接前的配置和确认对话框。

**功能规格**：
- 显示主机信息（名称、IP、环境、Agent 状态）
- 显示安全上下文（登录账号、认证方式、访问策略）
- 支持多凭证选择（如有多个凭证）
- 连接前权限检查

**交互设计**：
- 对话框采用终端暗色主题，无圆角设计
- 清晰展示连接信息和安全状态
- 提供明确的"连接"和"取消"按钮

#### 2.1.5 SFTP 文件传输
**需求描述**：支持通过 SFTP 协议进行文件传输。

**功能规格**：
- 支持文件上传/下载
- 支持目录浏览
- 支持断点续传
- 显示传输进度和速度

**优先级**：P1（二期实现）

### 2.2 辅助功能

#### 2.2.1 会话审计
**需求描述**：记录所有终端操作，支持事后审计。

**功能规格**：
- 记录所有执行的命令
- 记录命令输出（可选，敏感信息脱敏）
- 记录会话开始/结束时间
- 支持按时间、服务器、用户筛选

#### 2.2.2 访问控制
**需求描述**：基于 RBAC 的访问权限控制。

**功能规格**：
- 支持访问策略配置（用户/角色 → 主机）
- 支持时间窗口限制
- 支持审批流程（可选）

#### 2.2.3 监控集成
**需求描述**：在终端工具栏显示主机监控信息。

**功能规格**：
- 显示 CPU、内存使用率
- 显示网络流量
- 支持点击跳转到详细监控页面

### 2.3 高级功能（未来规划）

#### 2.3.1 批量操作
- 同时在多台服务器执行相同命令
- 显示批量执行结果汇总

#### 2.3.2 文件编辑器
- 内置文本编辑器，直接编辑远程文件

#### 2.3.3 录像回放
- 会话录像回放功能
- 支持快进、暂停、跳转

## 三、非功能需求

### 3.1 性能要求
- 单个终端会话内存占用 < 50MB
- 会话切换响应时间 < 200ms
- 支持至少 20 个并发会话
- 终端输入延迟 < 50ms

### 3.2 安全要求
- 所有连接必须通过认证
- 支持公钥/密码认证
- 敏感信息（密码、密钥）加密存储
- 完整的审计日志

### 3.3 可用性要求
- 连接成功率 > 99%
- 系统可用性 > 99.5%
- 支持主流浏览器（Chrome、Firefox、Safari、Edge 最新版本）

### 3.4 兼容性要求
- 支持 SSH 协议版本 2.0
- 支持 RSA/ECDSA/Ed25519 密钥
- 支持 xterm、vt100、vt220 等终端类型

## 四、界面设计规范

### 4.1 整体风格
- 采用 VSCode 终端的暗色主题
- 无圆角设计（0px border-radius）
- 字体使用等宽字体（Menlo、Monaco、Consolas）
- 色彩方案：背景 #1e1e1e、前景 #cccccc

### 4.2 布局结构
```
┌─────────────────────────────────────────────────────────────┐
│ 活动栏 │ 资产树 │ 会话标签 │ 终端内容区 │              │
│ (48px) │(可调整)│  (35px)  │            │              │
├────────┴─────────┴───────────┴────────────┴──────────────┤
│                    终端工具栏 (32px)                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                      xterm 终端                            │
│                    (自适应高度)                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 组件规范
- **活动栏**：48px 宽，深色背景 #252526
- **资产树**：默认 240px，可拖拽调整（200px-600px）
- **会话标签**：35px 高，支持横向滚动
- **终端工具栏**：32px 高，固定在顶部
- **终端区域**：剩余空间全部用于终端显示

## 五、技术方案

### 5.1 前端技术栈
- **框架**：Vue 3 + TypeScript
- **终端模拟**：xterm.js + xterm-addon-fit + xterm-addon-web-links
- **UI 组件**：Element Plus
- **状态管理**：Pinia

### 5.2 后端技术栈
- **语言**：Go
- **WebSocket 库**：gorilla/websocket
- **SSH 库**：golang.org/x/crypto/ssh

### 5.3 通信协议
- **终端 I/O**：WebSocket 双向通信
- **文件传输**：SFTP over SSH
- **API 请求**：HTTP/HTTPS

### 5.4 数据库设计
- **bastion_sessions**：会话记录
- **bastion_commands**：命令审计
- **bastion_files**：文件传输记录

## 七、验收标准

### 7.1 功能验收
- [ ] 能够成功连接到 SSH 服务器
- [ ] 支持至少 10 个并发会话
- [ ] 会话切换响应流畅（< 200ms）
- [ ] 支持中文输入和显示
- [ ] 支持复制粘贴操作
- [ ] 所有操作有审计记录

### 7.2 性能验收
- [ ] 内存占用符合规格
- [ ] 终端输入延迟符合要求
- [ ] 长时间连接（> 8小时）稳定

### 7.3 安全验收
- [ ] 未认证用户无法连接
- [ ] 敏感信息加密存储
- [ ] 审计日志完整准确

## 八、风险与应对

### 8.1 技术风险
| 风险 | 影响 | 应对措施 |
|------|------|----------|
| WebSocket 连接不稳定 | 高 | 实现自动重连机制 |
| 大量并发导致内存溢出 | 中 | 限制并发数，实现会话池 |
| 浏览器兼容性问题 | 中 | 测试主流浏览器，提供 polyfill |

### 8.2 安全风险
| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 中间人攻击 | 高 | 强制使用 HTTPS/WSS |
| 凭证泄露 | 高 | 密钥加密存储，定期轮换 |
| 权限提升 | 中 | 严格的 RBAC 控制 |
