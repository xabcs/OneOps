## 🎯 按功能模块分层设计

### 设计原则

1. **高内聚、低耦合** - 每个模块独立，职责单一
2. **依赖倒置** - 模块间通过接口交互
3. **可测试性** - 便于单元测试和集成测试
4. **可扩展性** - 新增模块不影响现有模块
5. **符合 Go 规范** - 遵循 golang-standards/project-layout

## 📐 模块设计详解

### 1. CMDB 模块（资产管理）

**职责**：服务器资产全生命周期管理

**子模块划分**：
- `domain/` - 领域模型（Server、Credential、Tag、Group）
- `repository/` - 数据访问层
- `service/` - 业务逻辑层
- `handler/` - HTTP 处理器

**依赖关系**：
```
handler → service → repository → database
         ↓              ↓
       domain        database
```

**API 前缀**：`/api/v1/cmdb`

---

### 2. Bastion 模块（堡垒机）

**职责**：SSH 连接、会话管理、Web 终端

**特点**：
- 实时性强（WebSocket）
- 状态管理（会话状态）
- 安全要求高（SSH 密钥）

**依赖关系**：
```
handler → service → repository → database
  ↓              ↓           ↓
WebSocket      Session    SSH Key
Manager      Pool
```

**API 前缀**：`/api/v1/bastion`

---

### 3. K8s 模块（Kubernetes）

**职责**：集群管理、资源操作、权限控制

**子模块**：
- `domain/` - 集群、Pod、Deployment、Service、Ingress 等
- `service/` - K8s API 交互、终端会话
- `handler/` - 资源操作、权限检查

**特点**：
- 复杂领域模型（K8s 资源种类多）
- 实时性强（Pod 终端、日志流）
- 需要连接多个 K8s 集群

**API 前缀**：`/api/v1/k8s`

---

### 4. Monitoring 模块（监控）

**职责**：指标采集、告警规则、Agent 管理

**子模块**：
- `domain/` - Metric、AlertRule、Agent
- `service/` - 数据采集、告警判断、调度器
- `handler/` - 指标查询、告警配置

**特点**：
- 定时任务（Agent 指标采集）
- 外部集成（Prometheus、JumpServer）
- 数据量大（监控指标）

**API 前缀**：`/api/v1/monitoring`

---

### 5. IAM 模块（身份认证和授权）

**职责**：用户认证、角色管理、权限控制、菜单配置

**子模块**：
- `domain/` - User、Role、Permission、Menu、ApiResource
- `service/` - RBAC 业务逻辑、Casbin 集成
- `handler/` - 用户管理、角色分配、权限配置

**核心功能**：
- JWT 认证
- RBAC 权限模型
- Casbin 策略管理
- 动态菜单

**API 前缀**：
- `/api/v1/auth` - 认证相关
- `/api/v1/users` - 用户管理
- `/api/v1/roles` - 角色管理
- `/api/v1/permissions` - 权限管理

---

### 6. Audit 模块（审计）

**职责**：操作审计、登录日志、会话追踪

**子模块**：
- `domain/` - AuditLog、LoginLog、OperationLog
- `service/` - 日志记录、查询、导出
- `handler/` - 日志查询、统计

**特点**：
- 写入频率高
- 数据量大
- 查询复杂（多条件筛选）

**API 前缀**：`/api/v1/audit`

---

### 7. Application 模块（外部应用权限）

**职责**：外部应用权限同步、授权规则管理

**子模块**：
- `domain/` - Application、AuthorizationRule、Permission
- `adapter/` - GitLab、Jenkins、JumpServer 适配器
- `service/` - 权限同步、授权判断
- `handler/` - 应用管理、规则配置

**特点**：
- 外部集成（GitLab API、Jenkins API）
- 权限映射（外部权限 → 内部权限）
- 异步同步（定时任务）

**API 前缀**：`/api/v1/applications`

## 🔄 模块间通信

### 同步通信

```go
// 示例：CMDB 模块调用 Bastion 模块
package cmdb

import (
    "oneops/backend/internal/bastion/service"
)

type ServerService struct {
    bastionService *service.BastionService // 依赖注入
}

func (s *ServerService) ConnectServer(id uint) error {
    // 调用 Bastion 服务
    return s.bastionService.CreateSession(id)
}
```

### 异步通信

```go
// 示例：监控模块通知审计模块
package monitoring

import (
    "oneops/backend/internal/audit/service"
)

type AlertService struct {
    auditService *service.AuditService
}

func (a *AlertService) TriggerAlert(alert Alert) {
    // 异步记录审计日志
    go a.auditService.RecordAlert(alert)
}
```

### 事件驱动

```go
// 示例：定义事件接口
package events

import "context"

type Event interface {
    AggregateID() string
    OccurredOn() time.Time
}

type EventHandler interface {
    Handle(ctx context.Context, event Event) error
}

// 订阅者模式
type EventBus struct {
    subscribers []EventHandler
}

func (b *EventBus) Publish(event Event) {
    for _, sub := range b.subscribers {
        go sub.Handle(context.Background(), event)
    }
}
```

## 🗂️ Repository 层设计

### 统一接口

```go
// internal/pkg/database/repository.go
package database

type Repository[T any, ID comparable] interface {
    FindByID(ctx context.Context, id ID) (*T, error)
    FindAll(ctx context.Context, filter map[string]interface{}) ([]*T, error)
    Create(ctx context.Context, entity *T) error
    Update(ctx context.Context, id ID, entity *T) error
    Delete(ctx context.Context, id ID) error
}
```

### 具体实现

```go
// internal/cmdb/repository/server_repository.go
package cmdb

import (
    "context"
    "oneops/backend/internal/cmdb/domain"
    "oneops/backend/internal/pkg/database"
)

type ServerRepository struct {
    db *gorm.DB
}

func NewServerRepository(db *gorm.DB) *ServerRepository {
    return &ServerRepository{db: db}
}

func (r *ServerRepository) FindByID(ctx context.Context, id uint) (*domain.Server, error) {
    var server domain.Server
    err := r.db.WithContext(ctx).First(&server, id).Error
    return &server, err
}
```

```go
package cmdb

import (
    "context"
    "oneops/backend/internal/cmdb/domain"
    "oneops/backend/internal/cmdb/repository"
)

type ServerService struct {
    serverRepo *repository.ServerRepository
    // 依赖其他模块服务
    bastionService *bastion.Service // 跨模块依赖
}

func NewServerService(
    serverRepo *repository.ServerRepository,
    bastionService *bastion.Service,
) *ServerService {
    return &ServerService{
        serverRepo:     serverRepo,
        bastionService: bastionService,
    }
}

func (s *ServerService) CreateServer(ctx context.Context, req *CreateServerRequest) (*domain.Server, error) {
    // 业务逻辑
    server := &domain.Server{
        Name: req.Name,
        IP:   req.IP,
    }

    // 保存到数据库
    if err := s.serverRepo.Create(ctx, server); err != nil {
        return nil, err
    }

    // 异步创建监控
    go s.bastionService.SetupMonitoring(server.ID)

    return server, nil
}
```

```go
// internal/cmdb/handler/server_handler.go
package cmdb

import (
    "github.com/gin-gonic/gin"
    "oneops/backend/internal/cmdb/service"
)

type ServerHandler struct {
    serverService *service.ServerService
}

func NewServerHandler(serverService *service.ServerService) *ServerHandler {
    return &ServerHandler{
        serverService: serverService,
    }
}

// CreateServer 创建服务器
// @Summary 创建服务器
// @Tags CMDB
// @Accept json
// @Produce json
// @Param request body dto.CreateServerRequest true "创建请求"
// @Success 200 {object} dto.Response
// @Router /api/v1/cmdb/servers [post]
func (h *ServerHandler) CreateServer(ctx *gin.Context) {
    var req dto.CreateServerRequest
    if err := ctx.ShouldBindJSON(&req); err != nil {
        ctx.JSON(400, gin.H{"error": err.Error()})
        return
    }

    server, err := h.serverService.CreateServer(ctx, &req)
    if err != nil {
        ctx.JSON(500, gin.H{"error": err.Error()})
        return
    }

    ctx.JSON(200, gin.H{"data": server})
}
```

```go
        v1.DELETE("/servers/:id", h.DeleteServer)

        // 凭证管理
        v1.GET("/credentials", h.ListCredentials)
        v1.POST("/credentials", h.CreateCredential)

        // 标签管理
        v1.GET("/tags", h.ListTags)
        v1.POST("/tags", h.CreateTag)
    }
}
```

4. **代码审查** - 每阶段完成后进行审查

```go
type ServerRepository interface {
    FindByID(ctx context.Context, id uint) (*Server, error)
}

// 再实现

    db *gorm.DB
}

func (r *GormServerRepository) FindByID(ctx context.Context, id uint) (*Server, error) {
```

### 2. 依赖注入

```go
// 使用接口而非具体实现
type ServerService struct {
    serverRepo ServerRepository  // 接口而非具体类型
}
```

### 3. 事件驱动

```go
// 使用事件解耦模块
type ServerCreatedEvent struct {
    ServerID uint
    Time      time.Time

// 订阅事件
eventBus.Subscribe("server.created", func(event Event) {
    // 处理事件
```

```go
// 统一错误定义
```
