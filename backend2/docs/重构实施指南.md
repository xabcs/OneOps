# OneOps 后端重构实施指南

## 📋 重构概述

本指南基于**功能模块分层方案_修正版.md**，将 OneOps 后端从技术分层（MVC）改造为业务功能模块分层（DDD）。

### 核心改进

| 改进项 | 说明 |
|--------|------|
| **CMDB + Bastion 合并** | 堡垒机作为 CMDB 的功能扩展，非独立模块 |
| **System = IAM** | 系统管理模块即 IAM（用户、角色、菜单、权限） |
| **Authorization 独立** | 授权中心处理外部应用权限（GitLab、Jenkins、JumpServer） |
| **按业务分层** | 从技术分层（controller/service/model）转为业务模块分层 |

## 🎯 模块划分

### 核心业务模块

```
internal/
├── cmdb/                    # CMDB 模块（含堡垒机）
│   ├── domain/             # 服务器、会话、策略、业务组
│   ├── service/            # 服务器管理、SSH连接、会话管理
│   ├── handler/            # HTTP 处理器
│   └── routes.go           # /api/v1/cmdb 路由
│
├── system/                  # 系统管理模块（IAM）
│   ├── domain/             # 用户、角色、菜单、权限、属性
│   ├── service/            # 认证、用户、角色、RBAC 服务
│   ├── handler/            # HTTP 处理器
│   └── routes.go           # /api/v1/system 路由
│
├── authorization/           # 授权中心模块
│   ├── domain/             # 应用、授权规则、用户组
│   ├── service/            # 应用管理、权限同步、适配器
│   ├── handler/            # HTTP 处理器
│   └── routes.go           # /api/v1/system/applications 路由
│
├── k8s/                     # K8s 模块
├── monitoring/              # 监控模块
├── audit/                   # 审计模块
└── pkg/                     # 共享库
```

## ⚠️ 注意事项

### 1. 编译错误处理

如果编译失败，可能需要手动修复：

```bash
# 查看编译错误
go build ./cmd/api 2>&1 | tee build-errors.log

# 常见问题：
# - 循环导入：检查 module 之间的依赖
# - 缺少包：确保所有文件都已移动
# - 路径错误：检查 import 路径是否正确
```

### 2. 路由验证

关键路由验证：

```bash
# CMDB 模块（含堡垒机）
curl -X GET /api/v1/cmdb/servers
curl -X POST /api/v1/cmdb/servers/:id/connect

# System 模块（IAM）
curl -X GET /api/v1/system/users
curl -X GET /api/v1/system/roles
curl -X GET /api/v1/system/menus

# Authorization 模块
curl -X GET /api/v1/system/applications
curl -X GET /api/v1/system/auth-groups
```

### 3. 数据库连接

确保配置文件路径正确：

```bash
# 检查配置文件位置
ls configs/config.yaml

# 如果配置文件不在 configs/，手动移动
mv internal/pkg/config/*.yaml configs/
```
